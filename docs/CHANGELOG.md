# CHANGELOG

## [2026-03-03]
- **Implemented Thematic Eras**: The game now evolves visually through 5 historical ages (Neolithic to Galactic). Each era requires both economic growth and study milestones to advance.
- **Added Research Expeditions**: Players can now send researchers on missions that progress with flashcard reviews, unlocking powerful permanent buffs (Gem chance, costs, etc.).
- **Added Study Streaks & Mastery Combos**: Consistency is now rewarded with daily production bonuses. High-quality recall (consecutive Easy ratings) triggers "Focus Bursts" for doubled production.
